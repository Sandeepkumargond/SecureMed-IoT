⚠️ Active Attacker — Tamper & Anomaly Detection

Simulates a MitM attacker flipping 1 bit in packet #5. Due to the PRESENT-80 Avalanche Effect, the decrypted payload produces non-physiological vitals which the host flags INVALID immediately.

How the Avalanche Effect Works

Flipping even 1 bit in the ciphertext propagates through 31 rounds of S-Box substitution and P-Layer bit permutation, flipping ≈50% of output bits. Any valid ECG/HR value becomes garbage — instantly detectable by the range validator.

ℹ️ About This Project

SecureMed-IoT — Lightweight Cryptography for Healthcare IoT Sensor Nodes

Cipher Specification

AlgorithmPRESENT-80
StandardISO/IEC 29192-2 · CHES 2007
Block size64 bits
Key size80 bits (10 bytes)
Rounds31 (+ final key addition)
S-Box4-bit → 4-bit (16 entries)
P-LayerP(i) = (i·16) mod 63

64-bit Payload Layout

[63:32] ECG raw (12-bit ADC → 32-bit field)
[31:16] Heart Rate (40–200 bpm)
[15:0] Timestamp (ms, low 16 bits)
[8:10] CRC-16/CCITT — bytes 0–7
[10:42] HMAC-SHA256 — bytes 0–9
Frame total: 42 bytes
